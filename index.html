Smart Suggestions

คำแนะนำอัตโนมัติจากข้อมูลล่าสุด

1 · Input Raw Data

อัปโหลดไฟล์ Excel (.xlsx) ที่มีชีต Inbound, Outbound, StockTake (redbox) — ระบบจะตรวจจับชีตอัตโนมัติและสร้าง Master + Reconcile ให้ทันที
⬆️
ลากไฟล์ .xlsx มาวาง หรือคลิกเพื่อเลือกไฟล์
รองรับไฟล์ Prototype Cycle Count.xlsx (ชีต Inbound / Outbound / StockTake redbox)
ทดลอง Dashboard และทุกเมนูได้ทันทีโดยไม่ต้องเตรียมไฟล์
โครงสร้างที่ระบบใช้: StockTake redbox = Inventory Onhand (G=D365, H=ASRS, I=Robot Miniload, J=Onfloor). Onfloor คำนวณ = D365 − ASRS − Robot. · Inbound = ยอดรับเข้า (Receive Qty) · Outbound = ยอดขายออก/คืน (QTY, ติดลบ=ออก)

2 · Item Master Setup

ทะเบียนสินค้า (สร้างอัตโนมัติจาก Raw Data) — แก้ไข Cost / Class / มิติ เพื่อใช้คำนวณมูลค่าและจัดกลุ่ม ABC. บันทึกอัตโนมัติในเครื่อง (localStorage)

ความถูกต้องสต็อก (Count Accuracy)

จาก SKU ที่นับแล้ว

4 · Daily Cycle Count

ระบบแนะนำรายการที่ควรไปนับวันนี้ (จาก movement, มูลค่า, และความผิดปกติของ location) — กรอกยอดนับจริงลงช่อง Count

5 · Compare & Tracking — วินิจฉัยผลต่าง

เฉพาะรายการที่นับแล้วและมีผลต่าง — ระบบวิเคราะห์ว่าดิฟมาจาก ขาเข้า / ขาออก / ระบบ และรายการที่อาจสลับกัน (swap)

Possible Swap (สินค้าที่อาจนับสลับกัน)

จับคู่รายการที่ variance ตรงข้ามกัน (+/−) ในกลุ่ม/brand เดียวกัน — อาจวางผิดตำแหน่งหรือสแกนสลับ

6 · History & Dashboard

บันทึกข้อมูลรายวันสะสมต่อเนื่อง — Stock Onhand, รับเข้า, จ่ายออก, และยอดดิฟของแต่ละวัน · กด “💾 บันทึกวันนี้” ที่มุมขวาบนหลังนำเข้าไฟล์ของแต่ละวัน
